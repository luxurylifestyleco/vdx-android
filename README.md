# VDX Android

Voice-first intent runtime. The first release does one job: call a person from what you said.

No login. No VDX cloud. One file stays on the phone.

You confirm before the dialer opens. On-device speech is the primary path. A cloud key is used only if you add one.

The release bar is in [FIRST-RELEASE-CALL-SPEC.md](FIRST-RELEASE-CALL-SPEC.md).
